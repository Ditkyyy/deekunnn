## 1. วิธีเปิดเว็บไซต์

ไม่ต้องติดตั้งอะไรทั้งสิ้น เพราะเว็บนี้เป็น **Static Website** (ไฟล์ธรรมดา ไม่มี Backend/ฐานข้อมูล)

1. แตกไฟล์ (Unzip) โฟลเดอร์ที่ได้รับมา
2. ดับเบิลคลิกไฟล์ `index.html`
3. เว็บจะเปิดขึ้นในเบราว์เซอร์ทันที (เช่น Chrome, Safari, Edge)

หากต้องการส่งให้แฟนดูผ่านลิงก์ (ไม่ใช่ไฟล์) แนะนำให้อัปโหลดทั้งโฟลเดอร์ขึ้นบริการฟรี เช่น **Netlify Drop**, **GitHub Pages**, หรือ **Cloudflare Pages** — เพียงลากทั้งโฟลเดอร์นี้ไปวาง ก็จะได้ลิงก์มาแชร์ทันที (ไม่ต้องตั้งค่า Server ใด ๆ)

## 2. วิธีเปลี่ยน GIF

ไปที่โฟลเดอร์ `assets/images/`

| ไฟล์ | ใช้ตอนไหน |
|---|---|
| `sorry.gif` | รูปที่แสดงตอนเปิดเว็บ (หน้าง้อ) |
| `happy.gif` | รูปที่แสดงหลังแฟนกด "ดีกัน ❤️" |

**วิธีที่ง่ายที่สุด:** เตรียมไฟล์ GIF ของคุณเอง แล้วตั้งชื่อไฟล์ให้เหมือนเดิมเป๊ะ ๆ คือ `sorry.gif` และ `happy.gif` จากนั้นนำไปแทนที่ไฟล์เดิมในโฟลเดอร์ `assets/images/` ได้เลย ไม่ต้องแก้โค้ดใด ๆ เพิ่ม

> 💡 แนะนำให้ใช้ GIF ที่มีสัดส่วนใกล้เคียงสี่เหลี่ยมจัตุรัส (1:1) จะแสดงผลสวยที่สุด และควรมีขนาดไฟล์ไม่ใหญ่มาก (แนะนำไม่เกิน 3-5 MB) เพื่อให้เว็บโหลดเร็ว

ถ้าอยากใช้ชื่อไฟล์อื่น ให้แก้ 2 จุดนี้ให้ตรงกัน:
- ไฟล์ `index.html` → บรรทัด `<img id="mainGif" src="assets/images/sorry.gif" ...>`
- ไฟล์ `js/script.js` → ในส่วน `CONFIG.gifs.happy = "assets/images/happy.gif"`

## 3. วิธีเปลี่ยนข้อความ

เปิดไฟล์ `js/script.js` ด้วยโปรแกรมแก้ไขข้อความ (Text Editor) เช่น Notepad, TextEdit หรือ VS Code

ด้านบนสุดของไฟล์จะมีส่วนที่เขียนว่า `CONFIG` — แก้ไขได้ตรงนี้เลย:

```js
texts: {
  happyMessage: "เย่.... 🥳",
  happySubLines: ["แฟนเค้าน่ารักที่สุดเลย ❤️", "รักเธอนะ"],
  happyGifAlt: "สติกเกอร์ดีใจน่ารัก ๆ",
},
```

ส่วนข้อความหน้าแรก ("ดีกันนะที่รัก 🥺") และข้อความบนปุ่มทั้งสอง ("ไม่" / "ดีกัน ❤️") แก้ได้ที่ไฟล์ `index.html` โดยหาบรรทัดต่อไปนี้แล้วพิมพ์ทับข้อความเดิม:

```html
<h1 class="main-message" id="mainMessage">ดีกันนะที่รัก 🥺</h1>
...
<button type="button" id="noBtn" class="btn btn-no">ไม่</button>
<button type="button" id="yesBtn" class="btn btn-yes">ดีกัน ❤️</button>
```

> ⚠️ อย่าลบ `id="mainMessage"`, `id="noBtn"`, `id="yesBtn"` ออก เพราะ JavaScript ใช้ชื่อเหล่านี้ในการทำงาน แก้ได้แค่ "ข้อความที่อยู่ระหว่างแท็ก" เท่านั้น

## 4. วิธีเปลี่ยนสี

เปิดไฟล์ `css/style.css` แล้วดูที่ด้านบนสุดของไฟล์ (ส่วน `:root { ... }`) จะเห็นตัวแปรสีทั้งหมดพร้อมคอมเมนต์กำกับไว้ เช่น

```css
--color-primary: #ff8fa8;        /* สีหลักของปุ่ม "ดีกัน ❤️" */
--color-bg-top: #fff8f1;         /* สีพื้นหลังด้านบน */
--color-text: #4a3b3b;           /* สีตัวอักษรหลัก */
```

แก้ค่าสี (รหัสสีแบบ `#RRGGBB`) ตรงนี้ได้เลย ไม่ต้องไปแก้ที่อื่นในไฟล์ทั้งหมด ระบบจะอัปเดตสีทั้งเว็บให้อัตโนมัติ

## 5. วิธีเปลี่ยนฟอนต์

ฟอนต์เริ่มต้นคือ **Mali** (หัวข้อ) และ **Prompt** (เนื้อหา) ซึ่งโหลดมาจาก Google Fonts และรองรับภาษาไทย

หากต้องการเปลี่ยนฟอนต์ ทำ 2 ขั้นตอนนี้:

1. ไปที่ [fonts.google.com](https://fonts.google.com) เลือกฟอนต์ที่ต้องการ (แนะนำเลือกฟอนต์ที่รองรับภาษาไทยถ้าจะใช้ข้อความไทย) แล้วคัดลอกลิงก์ `<link>` ที่เว็บมอบให้
2. เปิดไฟล์ `index.html` แล้วแทนที่บรรทัด `<link href="https://fonts.googleapis.com/css2?family=Mali...">` ด้วยลิงก์ใหม่ที่คัดลอกมา
3. เปิดไฟล์ `css/style.css` แล้วแก้ชื่อฟอนต์ในตัวแปรนี้ให้ตรงกับฟอนต์ใหม่:

```css
--font-heading: "Mali", "Prompt", "Noto Sans Thai", system-ui, sans-serif;
--font-body: "Prompt", "Noto Sans Thai", system-ui, sans-serif;
```

### ใช้ไฟล์ฟอนต์ของตัวเอง (ไม่ได้มาจาก Google Fonts)

ถ้ามีไฟล์ฟอนต์ของตัวเอง (เช่น `.otf`, `.ttf`) แนะนำให้แปลงเป็น `.woff2` ก่อน (ไฟล์เล็กลง โหลดเร็วขึ้น มีตัวแปลงฟรีให้ค้นหาได้ทั่วไป เช่น "otf to woff2 converter") แล้วทำตามนี้:

1. เอาไฟล์ `.woff2` ไปวางไว้ในโฟลเดอร์ `assets/fonts/` (ถ้ายังไม่มีโฟลเดอร์นี้ให้สร้างขึ้นมาเอง)
2. เปิดไฟล์ `css/style.css` เพิ่มโค้ดนี้ไว้บนสุดของไฟล์ (เหนือ `:root { ... }`):

```css
@font-face {
  font-family: "ชื่อฟอนต์ของคุณ";
  src: url("../assets/fonts/ชื่อไฟล์.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
```

3. เอาชื่อฟอนต์ (ตรง `font-family` ด้านบน) ไปใส่ไว้หน้าสุดในตัวแปร `--font-heading` หรือ `--font-body` ตามต้องการ

> ⚠️ **สำคัญ:** ฟอนต์แต่ละตัวมีตัวอักษรที่รองรับไม่เหมือนกัน (เช่น บางฟอนต์มีแค่ภาษาอังกฤษ/ลาว ไม่มีภาษาไทย) ถ้าใช้ฟอนต์กับตัวอักษรที่ฟอนต์นั้นไม่มี ตัวอักษรจะไม่ขึ้นแล้วเว็บจะเปลี่ยนไปใช้ฟอนต์ถัดไปในลิสต์แทนอัตโนมัติ — เทมเพลตนี้มีตัวอย่างการใช้ฟอนต์ลาวชื่อ "PB Melon" ใน `--font-heading` ไว้ให้ดูเป็นตัวอย่างแล้ว (ไฟล์อยู่ที่ `assets/fonts/PBMelon-Bold.woff2`)

## 6. วิธีปรับแต่งปุ่ม

- **ข้อความบนปุ่ม** — แก้ได้ที่ `index.html` (ดูข้อ 3)
- **สีปุ่ม** — แก้ได้ที่ `css/style.css` ตัวแปร `--color-primary` (ปุ่ม "ดีกัน") และ `--color-secondary-bg` / `--color-secondary-border` (ปุ่ม "ไม่")
- **ความไวในการหนีของปุ่ม "ไม่"** — แก้ได้ที่ `js/script.js` ในส่วน `CONFIG.behavior`:

```js
behavior: {
  edgeMarginPx: 16,        // ระยะห่างขั้นต่ำจากขอบจอ
  overlapBufferPx: 22,     // ระยะกันชนรอบปุ่ม "ดีกัน ❤️"
  minMoveDistancePx: 90,   // ต้องหนีให้ไกลจากจุดเดิมอย่างน้อยกี่ px
  maxPlacementAttempts: 20,
  heartBurstCount: 16,     // จำนวนหัวใจลอยตอน Happy Ending
},
```

> 🔒 **ข้อควรระวัง:** ปุ่ม "ดีกัน ❤️" ถูกออกแบบให้อยู่ตำแหน่งเดิมเสมอโดยตั้งใจ (เป็นหัวใจของธีมนี้) ไม่แนะนำให้แก้โค้ดส่วนตำแหน่งปุ่ม เว้นแต่จะเข้าใจ CSS/JavaScript เป็นอย่างดี

## 7. วิธีแก้ข้อความ Happy Ending

ข้อความที่ขึ้นหลังกด "ดีกัน ❤️" ทั้งหมด (ข้อความหลัก + ข้อความ 2 บรรทัดด้านล่าง) แก้ได้ที่ไฟล์ `js/script.js` ในส่วน `CONFIG.texts` (ดูตัวอย่างในข้อ 3 ด้านบน) สามารถเพิ่มหรือลดจำนวนบรรทัดใน `happySubLines` ได้ตามต้องการ เช่น

```js
happySubLines: [
  "แฟนเค้าน่ารักที่สุดเลย ❤️",
  "รักเธอนะ",
  "ขอบคุณที่ให้อภัยกันนะ 🥰",
],
```

## 8. โครงสร้างไฟล์

```
project/
│
├── index.html          → โครงหน้าเว็บ (HTML)
├── README.md            → ไฟล์นี้
│
├── css/
│   └── style.css        → สี, ฟอนต์, ดีไซน์, Animation ทั้งหมด
│
├── js/
│   └── script.js        → ข้อความ (CONFIG), พฤติกรรมปุ่ม, Happy Ending
│
└── assets/
    └── images/
        ├── sorry.gif    → รูปตอนเปิดเว็บ
        └── happy.gif    → รูปตอนกด "ดีกัน ❤️"
```

ไฟล์ HTML / CSS / JavaScript แยกออกจากกันชัดเจน แก้ไขจุดไหนก็ไม่กระทบไฟล์อื่นโดยไม่จำเป็น

## 9. Browser ที่แนะนำ

ทดสอบและใช้งานได้ลื่นไหลบนเบราว์เซอร์รุ่นใหม่ทุกตัว:

- Google Chrome (แนะนำ)
- Safari (iOS/macOS)
- Microsoft Edge
- Firefox

รองรับทั้งเครื่อง Desktop, Laptop, Tablet และ Mobile — ไม่ต้องติดตั้ง Plugin หรือ Extension ใด ๆ เพิ่มเติม

## สิ่งที่ Template นี้ "ไม่มี" (ตามการออกแบบ)

Template นี้เป็น **Static Website ล้วน ๆ** เปิดจากไฟล์ได้ทันที จึงไม่มี: ระบบ Login, ฐานข้อมูล, Backend, Admin Dashboard, ระบบสมาชิก, API หรือระบบเก็บข้อมูลผู้ใช้ใด ๆ ทั้งสิ้น ข้อมูลทั้งหมดอยู่ในไฟล์โค้ดเท่านั้น ปลอดภัย ไม่มีการส่งข้อมูลออกไปที่ใด
